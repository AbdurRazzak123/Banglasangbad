বাংলা সংবাদ — V31 Google SEO + Keyword Edition

এই ভার্সনে v30-এর ডিজাইন ও v26-এর sequential ad system অপরিবর্তিত রেখে SEO/keyword প্রস্তুতি যোগ করা হয়েছে।

নতুন সুবিধা:
1. Bangla News Google Sheet-এর J কলাম = Keywords / Tags (Optional)।
2. একাধিক keyword কমা/বাংলা কমা/লাইন ব্রেক দিয়ে লিখতে পারবেন।
3. details.html নিউজ লোড হলে keyword meta, Article schema keywords এবং দৃশ্যমান keyword chips তৈরি হবে।
4. Static pages-এ SEO keyword metadata যোগ করা হয়েছে।
5. Sitemap/robots/news sitemap-এর base URL বর্তমান GitHub Pages URL-এ ঠিক করা হয়েছে।
6. Google News sitemap workflow আগের মতো রাখা হয়েছে।

Google Sheet উদাহরণ:
A ID | B Category | C Headline | D Details | E Image1 | F Date | G Image2 | H Image3 | I Video | J Keywords / Tags

উদাহরণ J কলাম:
ঢাকা বৃষ্টি, জলাবদ্ধতা, রাজধানীর খবর, আজকের আবহাওয়া, বাংলাদেশ আবহাওয়া

গুরুত্বপূর্ণ:
- meta keywords নিজে থেকে Google ranking বাড়ায় না; Google-এর জন্য মূল বিষয় হলো ভালো, মৌলিক, সহায়ক ও নির্ভরযোগ্য সংবাদ।
- Keyword stuffing করবেন না। শুধু নিউজের সঙ্গে সরাসরি সম্পর্কিত 5–15টি শব্দ/ফ্রেজ ব্যবহার করুন।
- Google Search Console-এ sitemap submit করে নতুন নিউজের URL Inspection/Request Indexing ব্যবহার করুন।
