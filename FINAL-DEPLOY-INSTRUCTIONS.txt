BANGLASANGBAD — PROFESSIONAL FINAL PACKAGE

Target site:
https://abdurrazzak123.github.io/Banglasangbad/

WHAT THIS PACKAGE FIXES
- One crawlable static HTML page per Google Sheet news ID: /news/<ID>.html
- Article title, full text, canonical, Open Graph and NewsArticle JSON-LD are present in initial HTML
- sitemap.xml contains all generated article URLs
- news-sitemap.xml contains articles from the latest 2 days
- automatic build every 5 minutes, repository dispatch, or manual workflow run
- old details.html?id=... links are replaced by static article links
- old details.html remains only as a noindex compatibility redirect

ONE-TIME DEPLOYMENT
1. Extract this ZIP.
2. Copy/upload its contents into the ROOT of the Banglasangbad repository.
3. Keep your existing images, ads, CSS, JS, Google Sheet and any Search Console verification file.
4. GitHub Settings -> Pages -> Deploy from branch -> main -> /(root).
5. After the first push, the workflow “Sync Google Sheet to GitHub” runs automatically.
6. Wait for the workflow to become green. It will generate the news/ folder and article pages.
7. Test: https://abdurrazzak123.github.io/Banglasangbad/news/23.html (or any current Sheet ID).
8. In Google Search Console add the new site and submit:
   https://abdurrazzak123.github.io/Banglasangbad/sitemap.xml

GOOGLE SHEET
The “Bangla News” tab must remain publicly readable/published. Columns A-J are documented in GOOGLE-SHEET-FINAL-SETUP.txt.

IMPORTANT
Google controls crawling/indexing timing. This package fixes the technical architecture so Google can crawl real article HTML without depending on JavaScript rendering.


DESIGN FIX — ARTICLE PAGE
- The generated /news/<ID>.html page has the “সর্বশেষ সংবাদ” section AFTER the article, not inside it.
- Latest-news cards use absolute /news/<ID>.html URLs, so /news/news/<ID>.html cannot occur.
- The generator sorts the latest-news cards by parsed date when a valid date is available.
- If you upload/replace the repository and want the current Sheet data generated immediately, open GitHub Actions -> “Sync Google Sheet to GitHub” -> Run workflow.


IMPORTANT: Upload the contents of this ZIP directly into the GitHub repository root. Do not create an extra Banglasangbad-main/ or final test/ folder. The article pages already contain the “সর্বশেষ সংবাদ” section below the article, and the generator keeps it on future Google Sheet syncs.
