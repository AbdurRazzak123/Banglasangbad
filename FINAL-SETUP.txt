বাংলা সংবাদ — Google Sheet → GitHub → Website FINAL SYSTEM

1. Google Sheet-এর Bangla News tab build-time-এ GitHub Actions দিয়ে পড়া হয়। Website runtime-এ Bangla News tab সরাসরি পড়ে না।
2. News data news-data.json-এ আসে। ID অপরিবর্তিত থাকে; একই ID-র row edit করলে একই article page/update সংশোধন হয়।
3. Image 1/2/3 থাকলে GitHub Actions সেগুলো assets/news-media/ ফোল্ডারে কপি করার চেষ্টা করে। Google Drive share link ব্যবহার করা যায়; GitHub Actions-কে ফাইল দেখতে পারতে হবে (সাধারণত Anyone with the link → Viewer)।
4. Video URL ও Keywords/Tags data-তে থাকে।
5. index.html-এ একটিমাত্র Main News: GitHub data-র সর্বশেষ row। Latest News আলাদা থাকবে। যেকোনো headline/আরও পড়ুন-এ ক্লিক করলে /news/ID.html খুলবে।
6. home.html ও category pages GitHub-এর news-data.json থেকে খবর দেখায়। Google Sheet runtime fetch নেই।
7. Details /news/ID.html-এ নির্বাচিত নিউজের ৩-line teaser-এর পরের বাকি অংশ উপরে দেখানো হয়। নিচে একই category-র অন্য খবর ধারাবাহিকভাবে থাকে; বর্তমান ID বাদ থাকে। অন্য খবরের headline/আরও পড়ুন চাপলে সেই ID-র Details page খোলে।
8. Details page-এর URL-এ সবসময় নির্বাচিত News ID থাকে।
9. Existing SEO structure, canonical URL pattern, sitemap/news-sitemap generation এবং মূল page design অযথা বদলানো হয়নি।
10. Ads system আলাদা এবং অপরিবর্তিত: ads-loader.js এখনও Ads tab ব্যবহার করে।
11. GitHub Actions repository_dispatch (news_updated), scheduled sync এবং manual workflow dispatch—তিনভাবেই build চালাতে পারে।
