বাংলা সংবাদ — Google Sheet Media Setup

বর্তমান কলাম (আগের মতো):
A = ID
B = Category
C = Title
D = Details/News text
E = Image 1 (ঐচ্ছিক)
F = Date

নতুন optional media কলাম:
G = Image 2 (ঐচ্ছিক)
H = Image 3 (ঐচ্ছিক)
I = Video URL (ঐচ্ছিক)

ব্যবহার:
- শুধু ১টি ছবি: E পূরণ করুন, G/H/I ফাঁকা রাখুন।
- ২টি ছবি: E + G
- ৩টি ছবি: E + G + H
- ভিডিও: I-তে YouTube URL (youtu.be, watch?v=, shorts, embed) অথবা সরাসরি .mp4/.webm/.ogg URL দিন।
- ছবি/ভিডিও না দিলে কোনো media block দেখাবে না।
- হোম/ক্যাটাগরি পেজে GitHub-generated ৩-line teaser + আরও পড়ুন থাকবে।
- Details page-এ নির্বাচিত নিউজের teaser-এর পরের বাকি অংশ দেখাবে।
- Google Drive-এর ছবি GitHub Actions build-এর সময় assets/news-media/ ফোল্ডারে কপি করার চেষ্টা করবে; runtime-এ Google Sheet থেকে ছবি নেওয়া হবে না।
- Video URL data-তে থাকবে এবং প্রয়োজন অনুযায়ী Details page-এ দেখানো হবে।
