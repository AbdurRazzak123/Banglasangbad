১) Google Sheet Ads কেন দেখা যাচ্ছিল না
---------------------------------------
মূল সমস্যা পাওয়া গেছে ads-data.json এবং ads-loader.js-এর data-format mismatch-এ।

বর্তমান tools/generate_static_news.py Ads tab থেকে rows-কে সাধারণ array আকারে লিখছিল:
[
  ["Top", "Yes", "...", "...", "Title", "<script>..."]
]

কিন্তু ads-loader.js শুধু Google Visualization-এর object format পড়ছিল:
row.c[i].v

ফলে loader JSON ঠিকমতো download করলেও প্রতিটি row-এর Position/Active/Ad Code খালি হিসেবে পড়ছিল এবং কোনো matching ad তৈরি হচ্ছিল না।

FIX:
ads-loader.js v27 এখন দুই format-ই পড়ে:
- সাধারণ array row
- Google Visualization {c:[{v:...}]} row

বর্তমান ads-data.json-এর 4টি active ad row এখন loader-এর কাছে:
TOP = 1
MIDDLE TOP = 1
MIDDLE BOTTOM = 1
BOTTOM = 1

৩) Cache/version fix
---------------------
ads-loader.js-কে v27 করা হয়েছে এবং existing HTML/generated detail pages-এর loader URL নতুন version-এ নেওয়া হয়েছে:
20260915-ads-v28-mobile-fit-sheet-row-compatible

এতে পুরোনো cached v26 loader আটকে থাকার ঝুঁকি কমে।

৪) গুরুত্বপূর্ণ operational note
--------------------------------
Google Sheet পরিবর্তন করলে website-এর static ads-data.json সঙ্গে সঙ্গে বদলায় না।
বর্তমান architecture:
Google Sheet → GitHub Actions → ads-data.json → website

update-news-sitemap.yml প্রতি 5 মিনিটে sync করার জন্য configured আছে। GitHub Actions run এবং GitHub Pages deployment সম্পন্ন হওয়ার পর নতুন ad দেখা যাবে।

৫) Secondary limitation
------------------------
Ads loader-এর data-format bug ঠিক করা হয়েছে। এরপরও কোনো নির্দিষ্ট ad network-এর external script যদি server-side HTTP 403/blocked response দেয়, loader সেই network restriction bypass করতে পারবে না। সে ক্ষেত্রে Image URL + Click URL fallback ব্যবহার করা যায়।
